# yayoi-mcp — 弥生会計 × Claude（MCP）

弥生会計の仕訳データを、Claude Desktop / Claude Code から MCP 経由で読み書きするためのローカルサーバーです。

## 前提（2026-09 時点の調査）

| 区分 | 内容 |
|---|---|
| FACT | freee とマネーフォワード クラウド会計は公式 MCP サーバーを提供している。弥生については、公式 MCP サーバーの提供を確認できなかった |
| FACT | 弥生会計は「弥生インポート形式」のテキスト（CSV）による仕訳の取り込み・書き出しに対応している（弥生会計サポート情報「仕訳データの項目と記述形式」） |
| UNKNOWN | 弥生が一般開発者向けに会計データの読み書き API を公開しているかどうか。確認できたのは金融機関・カード会社などとの個別 API 連携のみ |

そこでこのサーバーは **CSV を橋渡しにする方式** を採っています。

```
弥生会計 ──(仕訳日記帳をエクスポート)──▶ CSV ──▶ yayoi-mcp ──▶ Claude（検索・集計・分析）
弥生会計 ◀──(人が画面でインポート)── CSV ◀── yayoi-mcp ◀── Claude（仕訳の作成）
```

弥生会計本体には直接書き込みません。取り込み前に人が中身を確認できる、安全側の設計です。

## ツール

| ツール | 内容 |
|---|---|
| `list_files` | データフォルダにある CSV の一覧 |
| `read_journal` | 仕訳 CSV を期間・勘定科目・キーワードで絞り込んで取得 |
| `summarize_by_account` | 勘定科目ごとの借方合計・貸方合計・差額 |
| `monthly_summary` | 月ごと・勘定科目ごとの推移（売上・経費の月次比較） |
| `find_duplicates` | 二重計上の疑いがある仕訳を探す（日付のずれ許容日数を指定可） |
| `list_accounts` | 使われている勘定科目・補助科目・税区分の一覧（新規仕訳の名称合わせ用） |
| `create_import_csv` | 仕訳から弥生インポート形式の CSV を新規作成（貸借一致を検証、上書き禁止、既定は Shift_JIS） |

ファイルアクセスは環境変数 `YAYOI_DATA_DIR` のフォルダ内に限定されます。

## セットアップ（Windows・弥生会計デスクトップ版）

1. [Node.js](https://nodejs.org/) の LTS 版をインストールする
2. このフォルダ（`tools/yayoi-mcp`）を `C:\yayoi-mcp` などにコピーする
3. **`setup.bat` をダブルクリックする**
   - 必要なパッケージが入り、Claude Desktop の設定（`%APPDATA%\Claude\claude_desktop_config.json`）に `yayoi` が追加されます
   - Claude Code が入っていれば、ユーザー全体の設定（scope: user）にも `yayoi` が登録されます（`claude mcp get yayoi` で確認）
   - 既存の設定は残ります。変更前の設定は `.bak-日時` の名前でバックアップされます
   - CSV の置き場として `ドキュメント\弥生CSV` フォルダが作られます（別の場所にしたいときは `setup.bat D:\経理\CSV` のように指定）
4. Claude Desktop は完全に終了し（タスクトレイのアイコンからも「終了」）、起動し直す。Claude Code は新しい会話を開く

Claude Desktop の「設定 → 開発者」に `yayoi` が表示されていれば接続できています。

### Mac / Claude Code の場合

```bash
npm install && node setup.mjs            # Claude Desktop に登録
claude mcp add yayoi -e YAYOI_DATA_DIR=/絶対パス/弥生CSV -- node /絶対パス/server.mjs   # Claude Code
```

### 更新したとき

`setup.bat` は置いたフォルダの `server.mjs` を登録する。リポジトリのブランチ切り替えで MCP が止まらないよう、実運用は専用フォルダ（例：`C:\弥生MCP`）にコピーして、そこで `setup.bat` を実行する。コードを更新したら同じフォルダへコピーし直し、Claude を再起動する（登録のやり直しは不要）。

## 使い方

1. 弥生会計で仕訳日記帳を「弥生インポート形式」でエクスポートし、`YAYOI_DATA_DIR` に保存する
2. Claude に話しかける
   - 「4月の消耗品費を一覧にして」
   - 「今期の勘定科目別の合計を出して」
   - 「売上高の月次推移を見せて。前月から大きく動いた月はある？」
   - 「二重計上っぽい仕訳がないか、前後3日のずれまで含めてチェックして」
   - 「このレシートの内容で仕訳CSVを作って。科目名は既存のものに合わせて」
3. 作成された CSV を確認し、弥生会計の「インポート」から取り込む

## 形式の確認状況（2026-09-26）

弥生会計デスクトップ版から実際に書き出した仕訳日記帳（2 か月分・240 行）と、毎月弥生に取り込んでいる既存の変換 CSV で照合済み。

- 列は 25 列、並び順は上記の想定どおり（`COLUMNS`）
- 識別フラグ：2000 = 1行の仕訳、2110 = 複合仕訳の先頭行、2100 = 中間行、2101 = 最終行
- 日付は西暦 `YYYY/MM/DD`（和暦にも対応済み）、文字コードは Shift_JIS、拡張子は `.txt` の場合あり
- タイプ列は 1行仕訳 = `0`、複合仕訳 = `3`。付箋1・付箋2 は `0`、調整は `no`
- 税金額は空欄にしない。省略時は税込金額から内税を切り捨てで計算する（例：75,400円・軽減8% → 5,585円）。内税以外の課税区分では税金額の指定が必須
- 複合仕訳も全行に借方・貸方の両方の科目を入れる（金額 0 円は可）。片側だけの行は `create_import_csv` がエラーにして作らない
- 複合仕訳は必ず 2 行以上（1 行だけで 2110 を使うと弥生が「仕訳の並びが不正」としてエラーにする）

未確認：

- `create_import_csv` で作った CSV を弥生で実際に取り込めるか（取り込みテストはバックアップ後に 1 件だけで行う）
- 弥生会計 Next でも同じ形式でインポートできるか（Next には複合仕訳 100 行までの制限があるとの FAQ あり）

**おすすめの確認方法：** 実際にエクスポートした CSV を `read_journal` で読み込み、弥生の画面表示と一致するか見てください。そのうえで `create_import_csv` で 1 件だけ作り、テスト用データに取り込んでから本番で使ってください。
