# giftmall-mcp — ギフトモールの店舗運営を Claude で

ギフトモール（giftmall.co.jp）に出店している「下関ふぐ老舗問屋山西水産」の注文と売上を、Claude から扱うための MCP サーバーです。

## 仕組み（なぜ API ではないのか）

ギフトモールには、出店者向けの公開 API が見つかりませんでした（2026-10-16 時点で調べた結果）。そこで、手元に届く次の2つを材料にしています。

| 材料 | どこから | 分かること |
|---|---|---|
| **注文確認メール** | 差出人 `oiwai@giftmall.co.jp`、件名「【ギフトモール】ご注文ありがとうございます」 | 注文番号、商品・数量・金額、のし、メモ、お届け日時、贈り物かどうか |
| **月別明細CSV** | 管理画面「売上集計 > 月別明細ダウンロード」（毎月1日ごろ案内メールが届く） | 発送済みにした注文、売上、システム利用料、振込額 |

**ギフトモール側を変える操作（在庫・商品・発送の登録など）はできません。** 発送済みの登録や送り状は、これまでどおり管理画面で行ってください。

## できること

| ツール | 内容 |
|---|---|
| `giftmall_add_order_emails` | 注文確認メールの本文を読み取って手元に記録（同じ注文は上書き）。**住所・電話番号は保存しない**（都道府県だけ） |
| `giftmall_open_orders` | まだ発送していない注文を古い順に「出荷準備リスト」にする。**のし・メモ・お届け日時**を目立たせる |
| `giftmall_mark_shipped` | 手元の「発送済み」記録（リストから外すだけ。ギフトモール側は変わらない） |
| `giftmall_monthly_reports` | 月ごとの売上・システム利用料・利用料率・振込額・件数・客単価 |
| `giftmall_month_detail` | 1か月分の明細と商品別の売れ行き |
| `giftmall_item_ranking` | 複数月の商品別ランキング |
| `giftmall_reconcile` | 月別明細と注文メールの突き合わせ（金額の食い違い・利用料率の外れ値）。相違は**案内メール受領後2営業日以内**に sd@giftmall.co.jp へ |
| `giftmall_customers` | 注文者ごとの回数・金額・贈り物の割合・のしの種類（個人情報を含む） |

定型の依頼（プロンプト）：
- `giftmall_sync_orders`：Gmail から注文メールを集めて取り込み、出荷準備リストを作る（Claude に Gmail のコネクタが必要）
- `giftmall_monthly_close`：月別明細を読み、照合し、相違があれば問い合わせの**下書き**を作る（送信はしない）

## セットアップ（PC）

```bash
cd ystudio-plus/tools/giftmall-mcp
npm install       # Windows で止められたら npm.cmd install
npm test          # 11件成功すればOK
```

Claude に登録します（どちらか）。

**Claude Code**
```bash
claude mcp add giftmall-shop -s user -- node /絶対パス/ystudio-plus/tools/giftmall-mcp/server.mjs
```

**Claude Desktop**（`claude_desktop_config.json` の `mcpServers` に追加）
```json
"giftmall-shop": { "command": "node", "args": ["/絶対パス/ystudio-plus/tools/giftmall-mcp/server.mjs"] }
```

月別明細CSVは、ダウンロードフォルダに置いておけば自動で見つけます（ファイル名に `giftmall` を含むもの）。別の場所なら `.env` の `GIFTMALL_CSV_DIRS` に書きます。

## 使い方の例

- 「ギフトモールの新しい注文を取り込んで、出荷準備リストを出して」
- 「9月のギフトモールの明細を確認して。メールと食い違いはない？」
- 「ギフトモールの利用料率、月ごとにどう変わってる？」

## 確認済み・未確認

確認済み（実物で）
- 月別明細CSV：2022年9月分の実ファイルで形式を確認。Shift_JIS、「■YYYY年M月度実績」→ 合計 →「■明細」→ 注文ごとの行。この実ファイルを読ませて、振込額・売上・利用料・各注文が正しく取れることを確認（2026-10-16）
- 注文確認メール：2026-10-16 に届いた実メールで書式を確認
- 相違の連絡期限（2営業日以内）と「月末締め翌月末支払」は、ギフトモールからの案内メールの記載

未確認
- 最近の月別明細CSVの列が2022年と同じか（違えば推測で計算せず、実際の列を示してエラーで止まる）
- 1通の注文メールに複数商品・複数お届け先がある場合の書式（複数商品は読み取る作り。複数お届け先は最初の1件だけ）
- ポイント利用分が明細の商品合計に影響しないか
- 管理画面「受注データエクスポート」のCSVには未対応

データは PC の `~/.giftmall-mcp/` にだけ保存されます（リポジトリには入りません）。
