## FACT（確認済み）
- BASE API のエンドポイント・スコープ・レート制限（5,000回/時・100,000回/日）は、BASE 公式の gist に記載がある
- 通常商品以外は API 経由で登録できない（公式ドキュメント記載）
- OAuth はこの実装のまま本物で通った（2026-10-10）
- トークン切れは `400 invalid_request`「アクセストークンが無効です」で返る（2026-10-10）

## 学び
- 本物の API に届かない環境で作るときは、想定の項目名を1か所（`F`）に集め、見つからなければ推測で計算せずにエラーにする。実機で違いが出たとき、直す場所がすぐ分かる
- 実機で違いが見つかったら、まずモックを実機に合わせる。そうすればテストが同じ間違いを二度通さない
