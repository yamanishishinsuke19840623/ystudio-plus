How it's made

映像は Canvas 2D、音は Web Audio API で、このページのコードがその場で生成しています（動画素材・音源ファイル・外部ツールは不使用。写真は shinsuke.jpg の1枚のみ）。96 BPM（テーマソング「潮風と、ふくと。」と同じテンポ）の拍にすべてのカットとモーションを合わせ、コード進行も同曲の C–G–Am–F を下敷きにしています。
