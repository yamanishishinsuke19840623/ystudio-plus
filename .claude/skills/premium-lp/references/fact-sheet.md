# 事実の棚卸し表（作る前に埋める）

ページとPVに載せる言葉は、この表の **FACT** と **VOICE**（本人の言葉・出典つき）からだけ選ぶ。
IDEA / PLAN は載せるなら「構想」と明記。UNKNOWN は載せない（本人に確認）。

| 区分 | 内容 | 出典（ファイル・URL・行） | 載せる場所 |
|---|---|---|---|
| FACT | 例: 明治12年（1879年）創業 | 元LP `yamanishi-suisan/index.html`（lp.yamanisi.co.jp） | ヒーロー・年表・PV |
| FACT | 例: 楽天市場 上位1%の優良ショップ | 元LP | 約束03・購入 |
| VOICE | 例: 「乗る舟は変わっても、船という本質は変わらない」— 4代目 山西伸典 | 元LP Owner's Message | 代表 |
| IDEA | | | |
| PLAN | | | |
| UNKNOWN | 例: あんこう鍋の高画質写真（手元にない） | — | 本人に依頼 |

## 掘る場所（優先順）

1. 本人の既存公式サイト/LPのソース（GitHub の別リポジトリにあることが多い）
2. 本人の別ページ（このリポジトリの `index.html`・`song.html`・`chamber.html` 等）
3. 本人のSNS投稿用画像リポジトリ（写真）
4. 検索結果（**二次情報**。数字や固有名詞は一次情報で裏を取る）

## 食い違いの扱い

- 例: 「明治12年（1878年）」と「明治12年（1879年）」→ 和暦換算で1879が正。元LPも1879。
  → 本人に一言伝えてから、リポジトリ全体を `grep` して全部揃える。
- 「147年」「148年目」のように数え方の違いは食い違いではない（創業147年＝148年目）。
- 写真の中の文字と字幕も照合する（市場の箱に「唐戸魚市」→ 字幕に「南風泊市場から」と書かない）。
