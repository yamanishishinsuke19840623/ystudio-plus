# 演出カタログ（山西水産LPで使った「おっ！」となる動き）

コードは `tools/motion-lab/src/yamanishi.js`。関数名＝演出名。ビルドは `npm run build:yamanishi`。
共通ルール: 動かすのは transform / opacity（filter少し）。`prefers-reduced-motion` では何も動かさず最終状態を見せる。
初期状態で隠すのは `.js` クラス配下だけ（app.js が2.5秒で読めなければ解除）。

| 演出 | 関数 | 中身 | 効かせどころの数値 | スマホ / 動き控えめ |
|---|---|---|---|---|
| ロゴが膨らむオープニング | `opening` | ロゴがばねで出る → 拍に合わせ2回「ぷくっ」(scaleX>scaleY) →「いらっしゃい！」→ `clip-path:circle()` で抜ける。2回目以降は sessionStorage で省略 | 膨らみ 1.18→1.36、抜け 0.8s | 同じ / 出さない |
| 写真入り文字ズーム | `heroScroll` | 巨大な筆文字に `background-clip:text` で写真。スクロールで最大40倍に拡大し、文字の**線の中**へ飛び込む → 全面写真に切替 → キャッチ | 拡大の中心は canvas に実フォントで文字を描き「一番太い線の中心」を自動計算 | 同じ / ズームなしで写真＋キャッチ |
| 額縁が正面に | `movie` | PVの枠が -4° 傾き・0.82倍から、スクロールで正面に | | 同じ / 静止 |
| 横に流れる年表 | `generations` | 縦スクロール量で横に5枚。正面以外の漢数字は傾いて小さく | セクション高 520vh | 縦積み＋数字がばねで出る / 縦積み |
| 年号カウンター | `ban` | ×を描く → 1592→1888 をスクロールで進める → 背景が墨→朱、×が○に、年号がばねで弾む | 文言は3段階で切替（禁止令→約300年→解禁） | 同じ / 1888の解禁状態で静止 |
| 速度で傾く帯 | `market` | 2本の帯が逆向きに流れ続け、スクロールが速いほど速く・斜めに | Lenis の velocity を使用、傾き最大14° | 同じ / 静止 |
| 重なるカード | `cards` | sticky で上に重なり、下のカードは0.9倍＋±2°で奥へ | 2枚目以降 top をずらす | 重なる（写真の視差なし） / 重ねない |
| 付いてくる商品写真 | `lineupFloat` | 行に乗るとその商品の写真がカーソルにばねで付く。横の速さで傾く | | 行にサムネを常時表示 / — |
| 見出しが跳ねて落ちる | `reveals` | 1文字ずつ上から落ち、ランダムに傾いてばねで止まる | stagger 0.03 | 同じ / 静止 |
| 社名がぷくっ | `footerPuff` | 巨大な社名が1文字ずつ 0→1.3→1 で膨らむ。PCではホバーでも膨らむ | | 同じ / 静止 |
| なめらかスクロール | `smoothScroll` | Lenis（lerp 0.1）。ページ内リンクも Lenis で移動 | | 同じ / 使わない |

## 選び方

- 1ページに「大技」は3つまで（例: 文字ズーム・年号カウンター・横年表）。残りは小技。
- 大技は**その会社の事実**とセットにする（年号カウンター＝禁止令と解禁の年、という事実があるから効く）。
- 業種の一発芸を1つ（ふぐ屋＝膨らむ）。ロゴやモチーフから考える。
