## 作っていて踏んだ穴（次の案件でも効く）
- **クラス名の衝突**: フッターの `.copy`（灰色）がヒーローの `.copy` に効いて、見出しが灰色になった → 汎用名は避ける（`.copyright`）
- **子孫セレクタの巻き込み**: `.num span{font-size:14px}` が数字の `<span data-count>` まで小さくした → `.num>span`
- **円の中の余白を % で書かない**: `padding:12%` は親の幅基準なので、スマホで泡が縦長につぶれた → `calc(var(--s)*.1)`
- **Motion の transform 上書き**: `translate(-50%,-50%)` で中央寄せした要素を `animate({scale})` すると位置がずれる → left/top を calc で出す
- **1文字ずつ分けた見出しの句読点**: 「、」「。」だけが次の行に落ちる → 分けるときに句読点は前の文字と同じ箱に入れる。
  さらに意味の切れ目を `<span class="ln">`（nowrap）で包むと、変な所で折れない
- チェックでは Google Fonts だけ通す（`page.route` で fonts.g* 以外の外部を止める）と、本番に近い見た目でスクショできる

- コード: `tools/nightbubble-pv/`（`pv.html` = canvas 1枚に描く絵コンテ、`music.js` = オリジナルBGM、`render.mjs`）
