# 台本作成

## 手順
1. テーマ・切り口・想定尺・視聴者を確認（topics.json の項目でも可）。
2. 本人の VOICE（実際に語った言葉・メモ・過去の発言）があれば最優先で素材にする。
3. 構成：タイトル案3つ → 冒頭フック（15秒） → 本編3〜5章 → まとめ・CTA。
4. 本文は話し言葉、結論先出し、専門用語は最小限。
5. 実例・数字が必要な箇所は `[FACT:要確認]`。
6. 保存先：`tools/youtube-ai-dx-scripts/output/YYYY-MM-DD-ID-スラッグ.md`、ステータスは DRAFT。
7. 最後に「撮影前の FACT 要確認リスト」。

## 関連
- 自動生成は `tools/youtube-ai-dx-scripts/generate.mjs`（GitHub Actions で毎朝実行）。手で磨くときにこのスキルを使う。

## 共通原則：盛らずに、掘る
- 情報は FACT／VOICE／IDEA／PLAN／UNKNOWN に分けて扱う。FACT以外を事実として書かない。
- 数字・実績・事例・固有名詞・日時・肩書きは創作しない。必要な箇所は `[FACT:要確認]` と置き、最後に「要確認リスト」を出す。
- 足りない情報は推測で埋めず、本人（やまちゃん）に質問する。アイデアは大胆に、事実は保守的に。
