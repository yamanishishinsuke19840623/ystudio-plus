# 分析・振り返り（LEARN）

## データの取り方（優先順）
1. Windsor.ai の `youtube` コネクタが接続済みなら `get_connectors` → `get_fields` → `get_data` で取得。
2. 未接続なら本人に YouTube Studio のCSV／スクショを貼ってもらう。
3. データがなければ分析しない（数字を推測しない）。

## 手順
1. FACT：期間・動画ごとの数値を表にする（出典を明記）。
2. 見立て：伸びた/伸びなかった要因は「仮説（IDEA）」として書く。断定しない。
3. 次の打ち手を3つまで（検証方法と判断基準つき）。
4. 学びを新しいFACTとして残す：`tools/youtube-ai-dx-scripts/learnings.md` に日付付きで追記を提案。

## 共通原則：盛らずに、掘る
- 情報は FACT／VOICE／IDEA／PLAN／UNKNOWN に分けて扱う。FACT以外を事実として書かない。
- 数字・実績・事例・固有名詞・日時・肩書きは創作しない。必要な箇所は `[FACT:要確認]` と置き、最後に「要確認リスト」を出す。
- 足りない情報は推測で埋めず、本人（やまちゃん）に質問する。アイデアは大胆に、事実は保守的に。
