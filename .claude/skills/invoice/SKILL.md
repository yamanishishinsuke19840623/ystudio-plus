# 請求書づくり（PDF → Gmail下書き）

やまちゃんの原則「盛らずに、掘る」で進める。金額・日時・宛名・振込先は推測で埋めない。分からなければ過去のメールを掘る。それでも分からなければ本人に聞く。

## 1. 事実を集める（FACT）

本人の依頼文から次を拾う。

- 宛先（会社名・担当者名）
- 実施日時
- 内容
- 単価（税別か税込か）

足りない分と差出人の情報は Gmail で掘る。

- **差出人・振込先・振込期限のルール**：直近の自分の請求メールを検索して、署名と振込先をそのまま使う。
  - 検索例：`in:sent 請求書 Ystudioプラス`（例：2026/9/30「【月星建設様】AI活用指導料 ご請求書の送付（9月分）」）
  - 振込先・電話番号はこの公開リポジトリには書かない。毎回メールから取る。
  - これまでの振込期限は「請求日の翌月末日」。振込手数料は先方負担。
- **宛先のメールアドレス**：過去にその会社へ請求書を送ったメールを検索する。
  - 検索例：`in:sent 請求書 (会社名 OR 担当者名)`
- **社名の正式表記**：依頼文と実際の表記が違うことがある（例：「アーチ」→「株式会社ARCH」）。メールでの表記に合わせ、合わせたことを本人に伝える。

確認が要るものは作り終えてからまとめて聞く（作業は止めない）。例：

- 「単価」は1回あたりか1時間あたりか
- 誰に請求するか（商工会議所のエキスパートバンク経由の回は請求先が違う）
- 請求番号の付け方
- インボイス登録番号の有無

## 2. PDF をつくる

JSON を書いて、同じフォルダの `make_invoice.py` を実行する。出力先はスクラッチパッドにする（請求書は公開リポジトリにコミットしない）。

```bash
python3 -I .claude/skills/invoice/make_invoice.py invoice.json <スクラッチパッド>/invoice
```

JSON の形：

```json
{
  "file_name": "20261020_株式会社ARCH_AI活用指導料_請求書",
  "date": "2026年10月20日",
  "number": "20261020-ARCH",
  "due": "2026年11月30日",
  "to": {"company": "株式会社ARCH", "person": "橋本 千佳子"},
  "from": {"name": "Ystudioプラス", "person": "山西 伸典",
           "lines": ["〒…", "住所…", "電話：…（メールから）", "メール：…"]},
  "items": [
    {"name": "AI活用指導料（Instagram自動投稿）", "qty": 1, "unit": "回", "unit_price": 20000,
     "notes": ["2026年10月20日（火）16:00〜18:00", "やったことを1行で"]}
  ],
  "tax_rate": 10,
  "bank": ["銀行名（コード）支店名（コード）", "普通 口座番号　口座名義"],
  "bank_note": "※恐れ入りますが、振込手数料は貴社にてご負担をお願いいたします。"
}
```

- 時間単価で書くとき：`"qty": 2, "unit": "時間", "unit_price": 10000`
- 消費税は小計×税率（切り捨て）で計算する。

出力は `.pdf`（20KB前後）、`.png`（プレビュー）、`.b64`（Gmail添付用、3万字弱）の3つ。**PNG を必ず目で見て**確認する：宛名、金額、合計、振込先、はみ出し。

### フォントは埋め込む（既定）

- 既定は IPAゴシックの使う文字だけを埋め込む。どの閲覧アプリでも同じ見た目で開ける。
- サイズを抑える工夫（どれもスクリプトに入っている）：
  - fonttools で使う文字だけに絞り、ヒンティングを外す。
  - 輪郭の座標を 1/64em 刻みに丸める（印刷サイズでは見分けがつかない）。
  - 2026/10/20 の実績では 50KB から 22KB になった。
  - fonttools が無ければ `pip install fonttools`。
- `--light` を付けると、埋め込まない4KB前後の版になる。非常用。

### 守ること（実際に失敗したこと）

- **埋め込まない版は使わない。** スマホのGmailで次のことが起きた（2026/10/20）。
  - 「¥22,000-」が「\22,000-」と表示された。
  - 「PDFを表示できません」と出た。
- **「¥」を使わない。** 金額は「22,000円」と書く。スクリプトは ¥ ／ ￥ ／ バックスラッシュを見つけると止まる。
- **Chromium の印刷でPDFを作らない。** フォントを丸ごと埋め込んで40〜50KBになるうえ、レイアウトの調整もしにくい。

## 3. Gmail 下書きにする

`mcp__Gmail__create_draft` を使う。

- `attachments` には次の1件を入れる。
  - `filename`：`<file_name>.pdf`
  - `mimeType`：`application/pdf`
  - `content`：`.b64` の中身そのまま
- **base64 の写し方**（実際に失敗した。古いPDFの base64 の行が混ざり、添付が壊れた）
  1. `fold -w 2000 <file>.b64 > lines.txt` で2000字ずつに折る。
  2. `Read` で読み、1行目から順に、改行を入れずにつなげて `content` に入れる。
  3. 同じ会話で前に別のPDFの base64 を読んでいたら、作り直したあとの行を読み直してから写す。冒頭が同じで中身だけ違うので取り違えやすい。
- **作ったら必ず確かめる。**
  1. `get_draft`（`messageFormat: RAW`）を呼ぶ。結果は大きいのでファイルに保存され、そのパスが出る。
  2. `python3 -I .claude/skills/invoice/verify_draft.py <保存先> <元のPDF>` を実行する。
  3. `OK` が出るまで次へ進まない。
  4. `NG` は何文字目から違うかを教えてくれる。その下書きは `delete_draft` で消し、その行を読み直して作り直す。
- 送信はしない（下書きまで）。作り直したときは古い下書きを `delete_draft` で消して、重複を残さない。

本文の型（過去の送付メールに合わせた形）：

```
{会社名}
{担当者名} 様

いつもお世話になっております。
Ystudioプラスの山西です。

{お礼と、やったことを1〜2文。事実だけ}

{実施月/本日}の{内容}につきまして、下記のとおりご請求書をお送りいたします。
PDFを添付しておりますので、ご査収のほどよろしくお願いいたします。

- 実施日：{日付（曜日）時刻〜時刻（n時間）}
- 内容：{内容}
- ご請求金額：{税別}円（税別）／{税込}円（税込）
- お振込期限：{期限}（請求日の翌月末日）
- お振込先：{メールから取った振込先}
※恐れ入りますが振込手数料は貴社にてご負担をお願いいたします。

引き続きどうぞよろしくお願いいたします。

{メールから取った Ystudioプラスの署名}
```

件名の型：`【{会社名}様】{内容} ご請求書の送付（{日付や月}）`

## 4. 本人への報告

- 下書きへのリンク
- 宛先と件名
- 金額（税別、税込）
- 推測で決めたところ（単価の解釈、社名の表記、請求番号など）を短く並べる

最後に、送る前にスマホで添付を開いて確認してもらうよう一言添える。
