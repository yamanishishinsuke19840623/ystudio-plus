# 概要欄・メタデータ

## 出力
1. 冒頭2行（検索結果とスマホで見える部分に要点）。
2. 本文：動画の要約、こんな人向け、関連リンク。
3. チャプター：台本の章から `0:00 はじめに` 形式で作る。実際のタイムコードが不明なら `[時間:要確認]`。
4. ハッシュタグ3つ以内、タグ候補10個。
5. 固定コメント案（問いかけでコメントを促す）。
- リンク・SNSアカウント・URLは本人から提供されたものだけ記載（`CNAME` 等リポジトリで確認できるものは可）。

## 共通原則：盛らずに、掘る
- 情報は FACT／VOICE／IDEA／PLAN／UNKNOWN に分けて扱う。FACT以外を事実として書かない。
- 数字・実績・事例・固有名詞・日時・肩書きは創作しない。必要な箇所は `[FACT:要確認]` と置き、最後に「要確認リスト」を出す。
- 足りない情報は推測で埋めず、本人（やまちゃん）に質問する。アイデアは大胆に、事実は保守的に。
