# まちの夜景マップをつくる（three.js × 公開データ）

見本: `yasuoka-night/`（公開URL https://ystudio.yamanisi.co.jp/yasuoka-night/ ）
作ったときの記録と、まだ確かめていないこと: `yasuoka-night/KNOWLEDGE.md`（**最初に読む**）
環境まわりの詳しいノウハウ: このフォルダの `knowledge.md`

## 何をつくるものか

- 夕暮れ（17:00）から夜明け前（5:00）までの時間スライダーで、家の灯り・街灯・空・海・列車が変わる3Dの夜景地図
- **海岸線・駅・町名は公開データの実際の位置**で描き、建物ひとつひとつ・道・灯りの時間は**イメージ**として描く
- 見どころ（例: やすらガーデン、竜王山・鋤先山）を足して、「おっ、うちのまちだ」と思える地図にする

## 守ること（いちばん大事）

**盛らずに、掘る。** 地図は「本当の場所」と思われやすいので、事実と演出を混ぜない。

- 位置・名前・標高・営業時間などは、**確認できたものだけ**を事実として描く。出典をコードのコメントとページ内「この地図について」に書く
- 確認できない位置は「おおよそ」と**ラベルにも説明にも書く**（例: 鋤先山は山頂座標が未確認なので大字蒲生野の代表点に置き、「位置はおおよそ」と表示）
- 時刻表（終電など）は確認できない限り載せない。列車は「演出」と明記
- 建物・道はイメージであることを、画面の隅とページ内の説明に必ず書く
- ユーザーの言葉（VOICE）と資料の表記が違うときは、資料の表記で出し、どちらにするかを本人に聞く（例: 「鋤崎山」と言われたが資料は「鋤先山」）
- AI生成のイラストを表紙に使うときは「イラストはイメージです」と書く

## つくり方

1. **FACT を集める**（`knowledge.md` の「データの取り方」）
   - 海岸線: 国土数値情報 行政区域（niiyz/JapanCityGeoJson を git clone）
   - 駅: 駅データ.jp（piuccio/open-data-jp-railway-stations）
   - 町名の位置: 町丁目の代表点（geolonia/japanese-addresses）
   - 見どころの住所・時間・標高: WebSearch で探し、出典URLを控える
2. **data.js を生成する**: `yasuoka-night/tools/build_data.py` を複製し、上の方の定数を変える
   - `LAT0, LON0`（原点。中心の駅など）、`BBOX`（切り抜く範囲 経度・緯度）、`WANT`（駅名）、`ekidata_line_id`（路線ID）、`M_PER_UNIT`（1単位=何m。15mで約6km四方がちょうどいい）
   - 下関市以外は `geojson/<県>/<市区町村コード>.json` と、住所データのファイル名を変える
   - 実行: `python3 build_data.py <JapanCityGeoJson> <railway-stations> <japanese-addresses> > ../data.js`（shapely が必要）
3. **ページを複製して直す**: `yasuoka-night/index.html` と `app.js` をコピーし、名前・駅の英語表記（`EN`）・表示する町名（`TOWN_SHOW`）・見る場所（`VIEWS`）・見どころ（`YG` / `PEAKS` の部分）を差し替える
   - three.js は `vendor/` に同梱済み（CDNはこの環境から使えないため）。importmap で読む
4. **見どころを足す**
   - 施設: 緯度経度が取れなければ、住所の町丁目の代表点に置き「〇〇町〇丁目付近」と書く。営業時間が分かれば時間スライダーと連動させる
   - 山: `PEAKS` に標高と位置を入れると、ガウス形の山＋等高線（50mごと）になる。山の上の家は自動で消える
5. **表紙・サムネイル**: ユーザーの画像があれば `cover.jpg`（表紙）と `ogp.jpg`（1200×630、タイトルが入る位置で切り抜き）にして og/twitter メタタグを付ける
6. **確かめる**: Playwright（swiftshader）でPC・スマホのスクショを撮って目で見る。手順は `knowledge.md`
7. **公開**: ブランチ → PR → master にマージで GitHub Pages に出る（`ystudio.yamanisi.co.jp`）。トップページの制作例（`index.html` の `#map`）に載せる場合はそこも直す

## 返答で伝えること

- 何が実データで、何がイメージか
- 位置や名前で確かめられなかったもの（UNKNOWN）と、本人に確認したいこと
- 公開した場合は、こちらの環境から本番サイトを開けないので、本人に表示確認をお願いする
