# カメラワークの名前で演出する

「いい感じにおしゃれに」では狙った動きは出ない。**映像の名前で決めて、名前で作る**。
名前に「秒数・速さ・被写体」を添えると狙いがぶれない（例: 「泡に向かって、ゆっくりドリーイン」）。

- 24種の一覧と「Webでの作り方」: `names.md`（やまちゃんが共有したチートシート24が出典）
- そのまま貼れるコード: `recipes.md`（Motion のバニラJS。`tools/motion-lab/` でビルドする前提）
- 実装の見本: `tools/motion-lab/src/nightbubble.js`（関数ごとにカメラワークの名前をコメントしてある）

## 進め方

1. **場面ごとに名前を1つ（多くて2つ）決める**。表にしてから作る。
   | 場所 | 名前 | 何を・どのくらい |
   |---|---|---|
   | ヒーロー | ドリーズーム | 泡を画面いっぱいまで、中の写真は1.45→1倍 |
2. **大技は1ページ3つまで**。残りは小技（ばねで出る・1文字ずつ落ちる）。
   大技は**その会社の事実やモチーフ**と組む（泡の事業＝泡の中へドリーイン、ふぐ屋＝ぷくっと膨らむ、年号の事実＝タイムラプス）。
3. **カメラ＝スクロール**と読み替える。縦に動かした量を、横移動（パン）・拡大（ドリー）・ぼかし（ピント）に変える。
   PVでは1コマずつ描くので、映像の意味のまま使う（`premium-lp/references/pv-pipeline.md`）。
4. **関数名・コメントに名前を書く**（`// ── ギャラリー（パン＋ホイップパン＋ラックフォーカス）──`）。次に直すとき、名前で話が通じる。
5. **ユーザーへの説明も名前で**。「ヒーローはドリーズーム、ギャラリーはパン＋ホイップパン」と表で見せる。

## 守ること

- スマホ（指で触る端末）はブラウザ本来のスクロール。重い演出（毎フレームの blur・長い固定区間）はPCだけ。
  スマホのパンは横スワイプ（`scroll-snap`）に置き換える。
- 動き控えめ（`prefers-reduced-motion`）では全部止めて、最後の状態を見せる。
- 動かすのは transform / opacity / clip-path（filter は少しだけ）。
- Motion の `animate({scale})` は要素の transform を上書きする。`translate(-50%,-50%)` で中央寄せした要素は位置がずれるので、left/top を calc で出す。
- 手持ち風・ダッチアングル・ホイップパンは**やりすぎると酔う**。揺れ±2px、傾き6°以内、ブレ6px以内が目安。
- 確認は `npm run check`（PC・スマホ・動き控えめ）＋途中のスクロール位置のスクショを目で見る（演出は途中が一番崩れる）。
