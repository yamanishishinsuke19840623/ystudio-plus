# 公開前FACTチェック

## 手順
1. 対象テキストを文単位で FACT／VOICE／IDEA／PLAN／UNKNOWN に分類した表を作る。
2. 特に重点チェック：数字、日付、固有名詞、肩書き・資格、実績、人間関係、引用、効果の断定表現。
3. 根拠があるもの（リポジトリ内資料・本人提供資料）は出典を併記。ないものは「要確認」または「削除/言い換え案」。
4. 残っている `[FACT:要確認]` プレースホルダーを全て列挙。
5. 判定：公開OK／要修正（修正点リスト）。
- 公開前の最終関門なので、迷ったら「要確認」に倒す。

## 共通原則：盛らずに、掘る
- 情報は FACT／VOICE／IDEA／PLAN／UNKNOWN に分けて扱う。FACT以外を事実として書かない。
- 数字・実績・事例・固有名詞・日時・肩書きは創作しない。必要な箇所は `[FACT:要確認]` と置き、最後に「要確認リスト」を出す。
- 足りない情報は推測で埋めず、本人（やまちゃん）に質問する。アイデアは大胆に、事実は保守的に。
