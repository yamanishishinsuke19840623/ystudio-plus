# シャボン玉教室 小学1年生130人分 必要量リスト

## 元にした資料（FACT）

- Googleドライブ「しゃぼん玉をつくろう、とばそう、とろう　02.pptx」（2025-07-17版）
- 山口県セミナーパーク 維新アカデミー事業（2025年7月21日）のワークショップ②で使った資料

資料に書かれている1人分のレシピ（割れないしゃぼん玉液）:

| 材料 | 1人分 |

| 水 | 100ml |
| 砂糖 | 30g |
| 食器用洗剤 | 12.5ml |
| 洗濯のり | お好みで（分量の記載なし） |

## 130人分の必要量（計算）

| 材料 | 130人分（ちょうど） | 予備20%込み（おすすめ） |

| 砂糖 | 3,900g（3.9kg） | 約4.7kg → **1kg袋×5袋** |
| 食器用洗剤 | 1,625ml | 1,950ml → **約2L** |
| 洗濯のり | 分量の記載なし（要確認） | ― |
| モール | 1人あたり本数の記載なし（要確認） | ― |

※ 予備20%は、こぼす・作り直す・欠席分の入れ替えなどを見込んだ **目安（IDEA）** です。

## まとめて作るときの比率

資料の比率 **水10 : 砂糖3 : 洗剤1.25** をそのまま大きくしたもの:

| 量 | 水 | 砂糖 | 洗剤 |
|---|---|---|---|
| 10人分 | 1L | 300g | 125ml |
| 30人分 | 3L | 900g | 375ml |
| 130人分 | 13L | 3.9kg | 1,625ml |

作り方（資料どおり）: ① 水に砂糖を入れ、溶け残りがないようしっかり混ぜる → ② 洗剤を入れ、泡を立てないように混ぜる → 完成。
