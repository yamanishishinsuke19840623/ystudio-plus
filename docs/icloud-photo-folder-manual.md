# 月星建設 iCloud写真フォルダ 消失確認マニュアル

## 目的

iCloud写真で作成していたフォルダ（アルバム）が見当たらなくなった際に、
慌てて再作成する前に「本当に消えたのか」「どこかで見えなくなっているだけなのか」を
切り分けるための確認手順です。

## 前提（現時点でわかっていること／わかっていないこと）

- **FACT**：iCloud写真でフォルダ（アルバム）を作って写真整理をしている。
- **FACT**：以前作ったフォルダが見当たらなくなった。
- **UNKNOWN**：消えた原因（誤操作／別アカウントでの操作／共有アルバムの解除／同期不良／ストレージ超過など）は未確認。
- **UNKNOWN**：管理しているアカウントが個人用か会社共有用か、端末が何台あるか。

原因を決めつけず、以下の手順で一つずつ確認してください。

## 確認手順

### STEP1：見ている場所を変えて確認する

- iPhone/iPadの「写真」アプリ →「アルバム」タブで、絞り込み表示（「共有アルバムのみ」等）がかかっていないか確認する。
- パソコンやブラウザから **iCloud.com/photos** にログインし、同じフォルダが見えるかを確認する。
  → 端末側だけの表示不具合か、iCloud側で実際に消えているのかを切り分けられます。

### STEP2：「最近削除した項目」を確認する

- 写真アプリ →「アルバム」→「最近削除した項目」を開く。
- 消えたフォルダに入っていた写真がここに残っていないか確認する（通常30日間保持）。
- 注意：この機能は「写真」の復元用で、アルバム（フォルダ）という入れ物自体の復元機能ではありません。

### STEP3：iCloud写真の設定を確認する

- 設定 →〔自分の名前〕→ iCloud → 写真 が **オン** になっているか確認する。
- 設定 →〔自分の名前〕→ iCloud → 「容量（ストレージ）」を確認し、上限に達していないか確認する。
  容量オーバーだと同期が止まり、他端末からフォルダが見えなくなることがあります。

### STEP4：共有アルバムかどうかを確認する

- 消えたのが「共有アルバム」だった場合、以下のいずれかで消えることがあります。
  - 共有相手が退出した
  - 自分以外の「主催者」がアルバムごと削除した
  - 自分が招待されていただけで、招待から外された
- 心当たりのある共有アルバムがあれば、参加者一覧・主催者が誰かを確認する。

### STEP5：ログインしているApple IDを確認する

- 設定の一番上に表示されているメールアドレス（Apple ID）を確認する。
- 端末を複数人・複数部署で共有している場合、いつの間にか別のApple IDでログインしていることがあります。

### STEP6：同期状況を確認する

- Wi-Fiに接続されているか確認する。
- 端末の空き容量が十分にあるか確認する（設定 → 一般 → 情報）。
- 時間を置いてから再度確認する（同期に時間がかかる場合があります）。

### STEP7：複数のデバイスで確認する

- iPhone／iPad／Mac／iCloud.com など、使える端末すべてで同じフォルダを探す。
- 1台でだけ消えている場合は、その端末のローカルな不具合・同期不良の可能性が高いです。
- 全端末・iCloud.comのいずれからも見えない場合は、iCloud側で実際に削除された可能性が高いです。

## 復元を試す

- iCloud.com → 写真 → 左側メニューの「最近削除した項目」から復元する。
- 上記で見つからない、重要なデータで至急復元したい場合は、Appleサポートに連絡する。

## 今後の予防策（要検討・社内でご判断ください）

- フォルダの命名ルールを統一する（例：`YYYYMMDD_案件名`）。
- 管理アカウント（誰の・どのApple IDで管理するか）を1つに決めて明文化する。
- 重要な写真は、iCloud写真とは別に定期的にバックアップを取る（外付けHDD、社内サーバー、Googleフォト等）。
- 月1回など定期的にフォルダ一覧のスクリーンショットを残し、消失に早く気づけるようにする。

## 確認しておきたい事項（社内で要確認）

- 写真管理は個人のApple IDか、会社共有のApple IDか。
- 使っているのは通常の「アルバム」か「共有アルバム」か。
- 消えたフォルダは1つか、複数か。いつ頃気づいたか。
- 使用している端末（iPhone／iPad／Mac／台数）。

---
このマニュアルは一般的なiCloud写真の仕組みに基づく確認手順です。
月星建設内の運用ルール（誰が・どのアカウントで管理しているか等）は未確認のため、
社内で実態を確認したうえで加筆・修正してご利用ください。
